### Sobre

Contribuo em um pipeline de integração em Python que consolida dados do Jira e do Clockify em Excel e Postgres, com alertas automáticos para o time. Gosto de automação confiável: etapas isoladas, dados validados e testes rodando no CI.

- **Foco:** Pipelines de dados e automação com Python
- **Também trabalho com:** PostgreSQL, GitHub Actions, integrações com APIs REST e Excel
- **Disponibilidade:** Aberto a conversas e oportunidades
